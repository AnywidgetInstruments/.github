# Visual identity

<img alt="The anywidget instruments mark" src="mark-light.svg" width="96">

## The mark

A dial: a 270° scale split into three bands, one per instrument family
(industrial, automotive, aeronautics), eleven ticks and a needle. The bands
climb from deep blue to amber, as a reading moves from its normal range toward
a limit; the amber pin at the hub picks up the last band.

The mark is drawn with the same shapes and colours as the widgets themselves,
so the logo, the documentation and the instruments read as one family.

## Files

Generated by [`make.py`](make.py); edit the script, run `python3 brand/make.py`
and commit the result. Never edit the generated files by hand.

| File | Use |
|---|---|
| `logo-light.svg`, `logo-dark.svg` | mark and wordmark, for READMEs and documentation headers |
| `mark-light.svg`, `mark-dark.svg` | the mark alone (favicons, small sizes) |
| `banner-light.svg`, `banner-dark.svg` | organization profile header |
| `avatar.svg`, `avatar.png` (512 px) | organization and package avatars; square corners, GitHub rounds them itself |
| `social-preview.svg`, `social-preview.png` (1280 × 640) | repository social preview |
| `icons/docs.svg`, `icons/code.svg`, `icons/try.svg` | link icons: documentation (book), source code (`</>`), live demo (play) |
| `buttons/*-light.svg`, `buttons/*-dark.svg` | link buttons of the organization profile |

In a README, pair the light and dark files:

```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/AnywidgetInstruments/.github/main/brand/logo-dark.svg">
  <img alt="anywidget instruments" src="https://raw.githubusercontent.com/AnywidgetInstruments/.github/main/brand/logo-light.svg" width="360">
</picture>
```

## Palette

The colours of the widgets' light and dark themes.

| Role | Light | Dark |
|---|---|---|
| Ink (text, needle) | `#111827` | `#f9fafb` |
| Muted text | `#4b5563` | `#9ca3af` |
| Face (background) | `#f9fafb` | `#111827` |
| Ticks | `#9ca3af` | `#4b5563` |
| Band 1, industrial | `#1e3a8a` | `#93c5fd` |
| Band 2, automotive; accent | `#2563eb` | `#60a5fa` |
| Band 3, aeronautics; highlight | `#f59e0b` | `#fbbf24` |

Link icons use `#3b82f6`, readable on both light and dark pages.

Red is reserved for alarms and emergency stops in the widgets; keep it out of
the identity.

## Typography

- Wordmark: `anywidget` regular in the muted colour, `instruments` bold in ink,
  lower case, no space. Sans-serif (Inter, falling back to the system font).
- Code, package names and keyword lines: a monospace font.

## Name

- The organization: **AnywidgetInstruments**.
- The project family, in prose: **anywidget instruments**; packages keep their
  own names (`anywidget-instruments`, `AnywidgetInstruments.jl`, …).
- Keywords: anywidget, instruments, instrumentation, widgets, industrial,
  automotive, aeronautics, aviation, HMI, SCADA, dashboards, notebooks,
  Jupyter, marimo, Julia, Grafana.
